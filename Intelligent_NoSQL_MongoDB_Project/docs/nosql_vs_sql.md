# NoSQL vs SQL – Project Notes

## SQL
- Stores data mainly in tables and rows.
- Uses predefined schemas.
- Relationships are commonly implemented with foreign keys and joins.

## MongoDB / Document NoSQL
- Stores data as BSON documents.
- Supports flexible document structures.
- Related data can be embedded or referenced depending on access patterns.

This project uses MongoDB documents plus references for students, courses and enrollments, following the syllabus focus on data modeling and relationships.
