# Mini Project Report

## Title
Intelligent Student & Course Management System using MongoDB

## Student
Ankit Kumar — 12311169

## Problem Statement
Educational systems store student, course and enrollment information that can be represented effectively with document-oriented NoSQL modeling. The project demonstrates how MongoDB can support CRUD, relationship modeling, validation, indexing, aggregation and application integration.

## Objectives
1. Create a MongoDB database and collections.
2. Demonstrate BSON and document-based storage.
3. Perform CRUD operations.
4. Demonstrate embedding and referencing.
5. Implement one-to-one, one-to-many and many-to-many relationship patterns.
6. Apply validation rules and constraints.
7. Create indexes and inspect query performance.
8. Build aggregation pipelines.
9. Integrate MongoDB with Node.js and Python.
10. Prepare data for intelligent / predictive analytics.

## Conclusion
The project covers the principal practical areas specified in the CSE494 syllabus and can be extended with a frontend, authentication, dashboards or a predictive model.
